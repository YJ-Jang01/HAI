# API Docs

This directory stores backend API documentation.

## What Belongs Here

- Endpoint specifications.
- Request and response schemas.
- Example payloads.
- Error codes.
- Auth notes.
- Integration contracts for AI agents and frontend.

## Initial APIs To Define

- Fetch demo items.
- Fetch reviews/evidence sources for selected items.
- Submit AI task request.
- Fetch AI-generated evidence or comparison result.
- Save interaction log.
- Save final study decision.

## Rule

Every endpoint used by frontend or AI code should have one documented example request and one documented example response.
